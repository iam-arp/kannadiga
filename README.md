# Kannadiga

Learn urban, conversational Kannada — the everyday Kannada spoken in Bangalore and other cities — through 18 scenario-based lessons: autos, markets, neighbors, food stalls, phone calls, bargaining, and more.

Each lesson covers:

- **Vocab** — flip cards with Kannada script, transliteration, and English meaning
- **Conversation** — a realistic back-and-forth dialogue for the scenario
- **Pronunciation practice** — listen via text-to-speech, then record yourself and get feedback
- **Quiz** — multiple-choice and fill-in-the-blank questions
- **Dictation** — listen and type what you hear

Progress is tracked locally in your browser (no account needed).

## Tech stack

- React + Vite
- Tailwind CSS
- react-router-dom (HashRouter)
- Web Speech API (speech synthesis + recognition) — best supported in Chrome
